# External asset ledger

Every third-party asset (model, texture, HDRI, audio, animation) used anywhere in the HD board/hall simulators must be listed here before it ships, with its source URL, author, license, and whether attribution is required. No exceptions.

| Asset | Source | Author | License | Attribution required? | Used in |
|---|---|---|---|---|---|
| CesiumMan (rigged/animated humanoid) | [KhronosGroup/glTF-Sample-Models](https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/CesiumMan), fetched from GitHub raw at commit time (not a runtime dependency — committed to this repo at `public/models/characters/cesium-man.glb`) | Cesium (Analytical Graphics, Inc.) | [CC BY 4.0](http://creativecommons.org/licenses/by/4.0/) | Yes | Part A hall simulator's `ArbiterPatrol` (`src/components/simulation/CharacterRig.tsx`) — the walking-arbiter figure patrolling the table row. |
| Classroom desk + office chair (real modeled geometry, extracted meshes only, no textures) | User-provided local file (`classroom.blend`, a Christophe Seux Cycles benchmark demo scene) — not redistributed in this repo, only the exported result | Christophe Seux | Not independently verified; used with the user's explicit authorization (see NOTES.md/HALL_SIM.md provenance note) | Not verified — treat as attribution-required until confirmed otherwise | Part A hall simulator's table kit (`public/models/hall/table-kit.glb`, generated by `tools/blender/table_kit_generate.py`). |

The board simulator (Part B) uses zero external binary assets — pieces and board are generated procedurally in Three.js (`src/lib/chess-pieces.ts`) with no textures beyond flat PBR materials. The hall shell (`public/models/hall/hall.glb`) is likewise fully procedural (`tools/blender/hall_generate.py`, flat PBR only, no external textures) and needs no row here.
